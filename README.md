# Отчёт по авансовым платежам договоров

Программа формирует отчёты по фактически выплаченным суммам и остаткам оплаты по работам и договорам на указанную дату.

## Требования

- Python 3.10 или новее.
- Сторонние библиотеки не требуются.

## Запуск

Требуется Python 3.10 или выше. Сторонние библиотеки не используются.

### Интерактивный режим

Запуск без аргументов:

```bash
python main.py
```

Программа последовательно запросит:

- папку с исходными CSV-файлами;
- дату отчёта в формате `YYYY-MM-DD`;
- папку для сохранения отчётов.

Для каждого параметра можно нажать Enter, чтобы использовать значение по умолчанию:

- исходные данные: `data`;
- дата отчёта: `2026-11-10`;
- отчёты: `reports`.

### Режим командной строки

Параметры можно передать непосредственно при запуске:

```bash
python main.py --date 2026-11-15
```

Доступные аргументы:

| Аргумент | Назначение | Значение по умолчанию |
|---|---|---|
| `--data-dir` | Папка с исходными CSV-файлами | `data` |
| `--date` | Дата отчёта (`YYYY-MM-DD`) | `2026-11-10` |
| `--output-dir` | Папка для сохранения отчётов | `reports` |

Пример с указанием всех параметров:

```bash
python main.py --data-dir input --date 2026-11-15 --output-dir output
```

Если передан хотя бы один аргумент командной строки, программа работает в режиме CLI и не запрашивает интерактивный ввод.

## Результаты

Программа формирует два файла:

### work_report.csv

Отчёт по каждой работе:

- стоимость работы;
- прямая оплата;
- сумма, распределённая из общих платежей;
- всего выплачено;
- остаток к оплате;
- переплата;
- финансовый статус.

### contract_report.csv

Итоги по каждому договору:

- сумма договора;
- всего выплачено;
- остаток к оплате;
- переплата;
- нераспределённые средства.

Файлы сохраняются в кодировке `utf-8-sig` с разделителем `;`, поэтому их можно открывать в Excel.

## Проверка данных

Перед расчётом программа проверяет исходные файлы.

Критические ошибки блокируют формирование отчётов. Предупреждения отображаются в консоли, но не блокируют расчёт.

## Тестирование

Для запуска автоматических тестов используется стандартный модуль `unittest`:

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют распределение платежей, валидацию исходных данных и формирование отчётов.
